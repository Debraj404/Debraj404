Featured Projects
Project	Description
AXI3-to-AXI5 Protocol Bridge	Co-designed a cycle-accurate AMBA bridge in SystemVerilog. Built a parameterized AXI3 Master IP (32-bit data/address, 4-bit ID) with out-of-order transaction tracking, and a custom testbench with a memory emulator that injects random backpressure. RTL written with synthesis in mind, targeting 250 MHz timing closure. AXI5 slave in progress.
Pong on Basys 2 FPGA	Pong game in Verilog HDL covering VGA signal generation, ball physics and collision detection, in pure hardware logic with no CPU. I handled the VGA module configuration using Xilinx ISE.
Audio Spectrum Visualiser	Splits audio into six frequency bands using second-order Sallen-Key bandpass filters and µA741 op-amps, and drives LED bar graphs through LM3914/LM3915 ICs to show real-time amplitude per band.
Smart Traffic Light System	AT89S52 (8051) based system that uses RFID to detect emergency vehicles and override the signal cycle via hardware interrupts. Includes IR sensors for dynamic lane timing, a 16x2 LCD and UART logging for debugging.
